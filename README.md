# NEW YORK TIMES | RPD | 09/12/2025

[![Demo on Vercel](https://img.shields.io/badge/vercel-demo-black?logo=vercel)](https://new-york-times-sage.vercel.app/)

### Stack: TypeScript, React, Redux (toolkit), RTK Query, TailwindCSS

## QUICK SETUP TO GO:

### 1 (CLONE REPOSITORY)

```cmd
git clone https://github.com/RPDPR/New-York-Times
cd New-York-Times
```

### 2 (INSTALL DEPENDENCIES):

```cmd
# npm
npm install

# yarn
yarn install

# pnpm
pnpm install

# bun
bun install
```

### 3 (EDIT ENVIRONMENT VARIABLES)

Create a file named **_.env_** in the project root and add:

```env
VITE_API_TOKEN=your_token # INSERT HERE YOUR API TOKEN ( YOU CAN GET YOUR OWN TOKEN AT https://developer.nytimes.com/ )
```

Change inner variable on your data

### 4 (RUN THE PROJECT)

```cmd
# development

# npm
npm run dev

# yarn
yarn dev

# pnpm
pnpm dev

# bun
bun dev


# production (build + preview)

# npm
npm run build
npm run preview

# yarn
yarn build
yarn preview

# pnpm
pnpm build
pnpm preview

# bun
bun build
bun preview
```
